## 🚀 How to Push to GitHub

To link this local repository with your GitHub account:

1. **Create a new repository on GitHub**:
   - Go to [github.com/new](https://github.com/new)
   - Repository name: `abhify.com` or `abhify.github.io`
   - Keep it **Public**

2. **Connect and push from your terminal**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/mrabhify7080-glitch/abhify.com.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - In your GitHub repository: **Settings** > **Pages**
   - Source: Deploy from branch `main` / `root`
   - Custom Domain: Ensure `abhify.com` is entered and Enforce HTTPS is checked.

4. **DNS Settings for abhify.com (at your domain registrar)**:
   - **Apex A Records**:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - **CNAME Record**:
     - Host: `www`
     - Target: `mrabhify7080.github.io` (or your GitHub username `.github.io`)
